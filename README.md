# slido-bot
bot for voting on slido  

# usage
only for multiple choice and you can only vote for one question (so far)  
./slido-bot.sh -h -- prints help  
./slido_bot.sh -u "\<url\>" -v \<question number\> -V \<number of votes\>  
35-49 votes seems to be the optimal number, after that Slido starts asking for Captcha  
same with .exe file (much faster).  

You can install it with provided .msi or compile it yourself, i don't care.
